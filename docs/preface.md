## I. Introduction

過去三年，我和社團夥伴在NTU校園內推動社區形式的堆肥，我們有一個放置堆肥箱的場地，並回收學生和餐廳的廚餘進行堆肥。這是一個嘗試改善現有都市有機廢棄物處理模式的長期專案，我們認為在地且去中心化的處理方式，更能適應都市的社會與環境特徵，且能帶來更大的社會效益。

但近期我們遇到許多技術性的阻礙，包括沒有工具修理壞掉的箱子、沒有就近可取得的木材、沒有運送重物的交通工具、沒有適合的場地進行修繕作業等。同時，和社區的合作也面臨許多溝通問題，我們難以將創新模式推廣到其他場域。我意識到，這些物質資源與溝通資本的欠缺，似乎反應更深層都市資源配置邏輯的問題，因為這些缺乏的事物事實上和人的基本需求都有密切關係，換句話說，若一個城市中的人沒有材料和知識修理自己的日常用品，也沒有和其他社區成員合作解決周遭問題的能力，很難說這個城市是具有韌性的。

從這個認知出發，我嘗試將最初的問題放到更大的理論架構理解，並發現歐洲已經存在urban manufacturing的論述與倡議。這個倡議的核心概念是讓城市re-industrialisation，支持現有製造業並鼓勵新型製造業湧現（這裡指的製造業也可以包含農業等初級產業），以回應城市去工業化後，以短期獲利為主的經濟活動佔據城市空間，排擠具有韌性的本地產業，並導致環境成本外部化等問題。然而，這種新型態的re-industrialisation會由哪些技術與物質構成、發生在城市的哪些地方，以及透過何種治理機制達成，仍是有待研究的問題。

這個概念讓我意識到以「產業」角度理解都市環境挑戰的重要性，因為城市事實上就是建立在一連串的經濟活動之上，這也代表，任何行動若沒有考慮背後的經濟邏輯，很難帶來系統性的改變。

這也讓我重新思考我們過去行動的定位與轉機。首先，物質資源的缺乏，應從整個都市物質流的角度去思考，而難以串聯的夥伴關係則需從供需關係來檢視。這讓原本「怎麼取得資材、如何推廣我們的方案」等單點、線性的問題轉變為「如何建立起穩固的關係網絡」，甚至是「如何建立一套新的地方經濟系統」的大哉問。

## II. Research Question

如何讓城市內的物質、技術和知識資源促成社區行動？

## III. Action aim

地方資料的缺乏，常導致社區行動面臨資訊落差與高昂的溝通成本，因為數據是關鍵的溝通工具，也是建立共識的基礎。不管是什麼行動都應該建立在對現況的全面了解上。因此，此計劃的第一步希望建立臺北市社區層級的資源資料庫，當中包括物質和非物質性的資源，如廢棄物流向、人口、土地利用等資料，將數據(data)轉化為知識(wisdom)，以利後續行動的展開。

長遠來看，我希望這個數據平台具有擴充與應用的潛力，開放不同社區行動者更新此份資料庫，進一步作為資源媒合與溝通的工具，

## III. Action aim（第 3 版，2026-10-26，使用者修訂）

從過往經驗，我發現地方資料的缺乏，常導致社區行動面臨資訊落差與高昂的溝通成本，因為數據是關鍵的溝通工具，也是建立共識的基礎。不管是什麼行動都應該建立在對現況的全面了解上。因此，此計劃的第一步希望建立臺北市社區層級的資源資料庫，當中包括物質和非物質性的資源，如廢棄物流向、人口、土地利用等資料，將數據(data)轉化為知識(wisdom)，以利後續行動的展開。另外，考量部分資料在鄰里尺度可能有所缺漏，本計劃將以台大社區堆肥據點為示範點，補充更細緻、驗證過的資料集，作為後續資料填充的範本。

長遠來看，我希望這個數據平台具有擴充與應用的潛力，開放全台北市不同的社區行動者更新此資料庫，進一步作為資源媒合與溝通的工具，最終成為支持台北都市再工業化的資料基礎。
