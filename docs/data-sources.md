# 資料來源

> 皆為初步清單，空間解析度、授權、更新頻率均待查核。

| 資料層 | 來源 | 備註 |
|---|---|---|
| 人口、年齡 | 內政部「社會經濟資料服務平台（SEGIS）」 | 可到最小統計區；待查核欄位與授權 |
| 職業、行業 | 主計總處「人口及住宅普查」（2020） | 空間解析度較粗；待查核可取得的最小單位 |
| 五金行、農具行、材料行 | 經濟部商工登記開放資料 | 以營業項目代碼篩選（如五金零售業）；代碼待查核 |
| 工廠、鐵工廠 | 經濟部工廠登記資料 | 待查核 |
| 廢棄資材、閒置空間、技術人力 | 田野調查、參與式登錄 | 需設計登錄表單與更新機制 |

## 個資與倫理
- 個人技能資料涉及個資法：自願登錄、取得同意、去識別化。
- 公開地圖不顯示可識別個人的精確位置；必要時以網格或統計區聚合。
